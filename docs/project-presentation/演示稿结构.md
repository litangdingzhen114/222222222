# 一部手机游海林村项目展示稿结构

本稿共 8 页，面向项目汇报和演示沟通，重点展示小程序当前最完整、视觉效果较好、能够体现业务闭环的页面。

1. 项目封面：统一游客入口与核心服务能力。
2. 产品定位：把分散的乡村服务集中到一个清晰入口。
3. 内容体验：首页、景点列表、田铺驿站、村树详情。
4. 导览能力：地图点位、路线推荐、智能导游。
5. 到访转化：慢直播、讲解预约、信息填写、研学报名。
6. 商业闭环：商品列表、商品详情、确认清单、收货信息、订单详情。
7. 持续运营：个人中心、民宿预订、意见反馈与后台维护范围。
8. 上线准备：前端、后台、服务端和第三方凭证接入状态。
